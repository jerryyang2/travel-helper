# 旅遊小幫手｜藍墨旅行手帳

手機優先、全繁體中文的單檔旅行規劃工具。

[開啟旅行手帳](https://jerryyang2.github.io/travel-helper/)

## 自己的城市，自己的手帳

選擇國家、城市、出發日期與 1–30 天天數，建立獨立旅程。「切換城市／旅程」可翻閱不同城市，新增旅程不會覆蓋原有安排。也可載入標示清楚的福岡六天範例。

- 藍墨線條、柔和紙色、城市封面、日期章與書籤分頁。
- 自訂封面標題與短句；每日手記會隨輸入自動保存，並包含在備份和列印手帳中。
- 封面隨城市自動換成原創 SVG 插畫，支援中文與英文城市別名。
- 已收錄 31 座城市：福岡、東京、京都、大阪、札幌、沖繩、首爾、釜山、濟州、曼谷、清邁、台北、台中、台南、高雄、花蓮、新加坡、香港、慕尼黑、柏林、巴黎、倫敦、紐約、雪梨、里斯本、羅馬、威尼斯、巴塞隆納、吉隆坡、舊金山、溫哥華。未收錄的城市使用清楚標示的通用旅行插畫；多城市旅程以名稱中第一個辨識到的城市為封面。

## 手機排行程

- 按住卡片的「拖曳」把手，放到其他彈性卡片的時間格以排序。
- 拖曳時下方會出現日期列，放到其他日期即可跨日移動。
- 點一下把手，也能以選單指定目的日期與時間。
- 航班與標記為固定的預約保留日期、時間；移動後提醒交通待確認及活動時間重疊。
- 住宿速查、可編輯行前清單、晴雨方案、外幣記帳與公開急難資訊卡。

## 資料保存

行程、手記、清單與支出保存在目前裝置的瀏覽器。預設不會上傳任何旅程。已實作可自行啟用的登入、跨裝置同步及旅伴檢視／編輯功能，需先連接自己的 Supabase 專案；不需要安裝外掛。請依 [雲端設定步驟](cloud/README.md) 完成資料庫、登入及寄信設定，再從「同步與分享」選擇上傳旅程。未設定時仍為本機模式，介面會明確顯示狀態。

請定期備份。「我的旅程」可匯出所有城市；頁尾可備份目前旅程。匯入單趟或多趟 JSON 會新增獨立旅程，保留既有資料。備份檔包含自行填寫的資料，請自行保管。

所有範例航班、住宿、天氣、費用與交通估算須依實際資料確認。安全資訊提供官方查詢入口，不會自動更新公告。Google 地圖、官方連結及線上字型需要網路；下載 HTML 可使用其餘內嵌功能。

## 發布與原始碼

首頁為 `index.html`；樣式、SVG 插畫、專屬 favicon 與互動程式直接內嵌。新增城市插畫可在 `CITY_ART` 集中維護，福岡範例集中於 `makeFukuokaSeed()`。

`.nojekyll` 讓 GitHub Pages 直接提供靜態檔案，發布來源為 `main` 分支根目錄。同步使用版本號防止覆蓋，同時修改的衝突會保留本機副本；登入、編輯權限由資料庫 RLS 控管。離線編輯先存本機；完成編輯並恢復連線後重試。

本儲存庫包含可公開的網站、資料庫設定、使用說明與開源授權。官方 Supabase JavaScript SDK 及其授權已內嵌於單檔 HTML；授權另存於 [THIRD_PARTY_NOTICES.txt](cloud/THIRD_PARTY_NOTICES.txt)。
