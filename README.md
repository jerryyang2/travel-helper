# 旅遊小幫手

手機優先、繁體中文的單檔旅行規劃工具。

## 使用網站

[開啟旅遊小幫手](https://jerryyang2.github.io/travel-helper/)

選擇國家、城市、出發日期與 1–30 天天數，建立空白旅程；也可套用標示清楚的福岡範例。

- 按住卡片上的「拖曳」把手，放到其他彈性卡片的時間格以排序。
- 拖曳時下方會出現日期列，放到其他日期即可跨日移動。
- 點一下把手，也能以選單指定目的日期與時間。
- 航班與標記為固定的預約保留日期、時間。移動後會提醒需要重查的交通段與活動時間重疊。
- 支援住宿速查、行前清單、外幣記帳、資料備份與還原、公開急難資訊卡。

行程、勾選與支出保存在目前裝置的瀏覽器；不會上傳至伺服器，也不會自動同步給旅伴。請定期使用網站內的備份功能。Google 地圖、官方資訊連結及線上字型需要網路。

所有範例航班、住宿、天氣、費用與交通估算均須依實際資料確認。安全資訊提供官方查詢入口，不會自動更新公告。

## 發布與原始碼

首頁為 `index.html`，樣式、SVG 插畫、favicon 與互動程式直接內嵌。`.nojekyll` 讓 GitHub Pages 直接提供靜態檔案；發布來源為 `main` 分支根目錄。

此儲存庫僅保留可公開的網站檔案與使用說明。
