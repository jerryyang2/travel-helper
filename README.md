# 旅遊小幫手｜藍墨旅行手帳

手機優先、全繁體中文的單檔旅行規劃工具。

[開啟旅行手帳](https://jerryyang2.github.io/travel-helper/)

## 自己的城市，自己的手帳

選擇國家、城市、出發日期與 1–30 天天數，建立獨立旅程。「切換城市／旅程」可翻閱不同城市，新增旅程不會覆蓋原有安排。也可載入標示清楚的福岡六天範例。

- 藍墨線條、柔和紙色、城市封面、日期章與書籤分頁；城市插畫加入細緻的街景、河岸、花草、旅人與小鳥。
- 自訂封面標題與短句；每日手記會隨輸入自動保存，並包含在備份和列印手帳中。
- 可從手機相簿加入自己的風景照，編輯說明、指定旅遊日期，並設為封面；隨時可切回城市插畫。
- 「待辦購物清單」可記錄名稱、數量、店家、備註及選填預估單價，勾選已購買；總覽與行前清單都有快捷入口。
- 封面隨城市自動換成原創 SVG 插畫，支援中文與英文城市別名。
- 已收錄 31 座城市：福岡、東京、京都、大阪、札幌、沖繩、首爾、釜山、濟州、曼谷、清邁、台北、台中、台南、高雄、花蓮、新加坡、香港、慕尼黑、柏林、巴黎、倫敦、紐約、雪梨、里斯本、羅馬、威尼斯、巴塞隆納、吉隆坡、舊金山、溫哥華。未收錄的城市使用清楚標示的通用旅行插畫；多城市旅程以名稱中第一個辨識到的城市為封面。

## 手機排行程

- 按住卡片的「拖曳」把手，放到其他彈性卡片的時間格以排序。
- 拖曳時下方會出現日期列，放到其他日期即可跨日移動。
- 點一下把手，也能以選單指定目的日期與時間。
- 航班與標記為固定的預約保留日期、時間；移動後提醒交通待確認及活動時間重疊。
- 住宿速查、可編輯行前清單、晴雨方案、外幣記帳與公開急難資訊卡。

## 備份與匯入

目前採用本機版，行程、手記、購物待辦及支出保存在目前裝置的瀏覽器；照片存於瀏覽器的本機照片儲存區。照片及旅程不會上傳 GitHub 或其他伺服器。

上方「備份與匯入」集中提供三個手機觸控按鈕：

- **備份目前旅程**：下載目前城市的完整 JSON 備份，包含照片、封面及購物清單。
- **備份所有城市**：將所有旅程與照片存成一份備份檔。
- **匯入備份檔**：讀取單趟或多城市備份，還原照片及購物勾選；新增為獨立旅程，保留既有城市與內容。

換手機或電腦時，先下載備份檔，再到另一台裝置開啟網站並匯入。清除瀏覽資料可能移除本機紀錄，請定期備份。備份包含自行填寫的內容，請自行保管。

新版含照片備份使用版本 2，亦支援舊版單趟及多城市備份。照片每趟最多 100 張、每張來源檔最多 20 MB，加入時轉成最長邊 1600 px 的 JPEG，並產生縮圖。一般支援 JPG、PNG、WebP；HEIC/HEIF 能否讀取依瀏覽器而定。

含照片的備份最大 60 MB；資料較多時請分別備份每趟旅程。縮短天數時，較後日期的照片會保留在整趟相簿。列印手帳會整理照片、購物待辦、每日手記與行程。

沿用舊版旅程資料；若曾下載共用旅程，其既有內容會保留為本機資料，不會修改遠端資料。雲端版本目前暫停，先前設定文件保留於 [版本存檔](cloud/README.md)。

所有範例航班、住宿、天氣、費用與交通估算須依實際資料確認。安全資訊提供官方查詢入口，不會自動更新公告。Google 地圖、官方連結及線上字型需要網路；下載 HTML 可使用其餘內嵌功能。

## 發布與原始碼

首頁為 `index.html`；樣式、SVG 插畫、專屬 favicon 與互動程式直接內嵌。新增城市插畫可在 `CITY_ART` 集中維護，福岡範例集中於 `makeFukuokaSeed()`。

`.nojekyll` 讓 GitHub Pages 直接提供靜態檔案，發布來源為 `main` 分支根目錄。現行單檔 HTML 已移除雲端 SDK、登入與同步程式，保留城市切換、拖曳排序、跨日期移動和每日手記，加入風景照片與待辦購物清單。個人照片與備份檔不包含在公開儲存庫中。

本儲存庫僅包含可公開的網站、使用說明及先前雲端版本的設定與授權存檔。
